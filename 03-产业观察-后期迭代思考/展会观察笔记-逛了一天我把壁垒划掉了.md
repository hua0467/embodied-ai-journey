## 一、用逛车展的经验逛机器人展

我是学汽车的，逛展有职业惯性：看车展，先看三大件——发动机、变速箱、底盘，其余都是壳。这次逛机器人展，我下意识找机器人的"三大件"，很快定位到：**本体（硬件）、数据、模型**。台上机器人的表演我看得很少，时间全花在问这三样上。

当天是 ARE 2026（第 18 届深圳国际工业自动化及机器人展览会）、AGIC（深圳国际通用人工智能产业博览会）、GERX（全球具身智能机器人产业博览会）三展同场，我现场又报名进了 AGIC 的 Token 经济发展大会。一天下来，论坛、展台、交流三线并行，信息量比我在公司一周还大。

## 三、展台观察：热闹的台下，行业刚刚起步

听完论坛再逛展台，落差感很强。我观察到两条反直觉的现象（个人拙见，供吐槽）：

1. **大量展台停留在"卖爆米花"阶段**：卖咖啡、卖爆米花的机械臂到处都是，仔细一聊，基本都是预编程示教——人教一遍，机器重复一遍。真正搭载 VLA 的极少，世界模型只存在于 PPT 的概念区。而且展台驻场的大多是销售，技术人员不多，讲解主要靠话术。反过来想：真有技术实力的公司，应该会派技术驻场答疑。
2. **算力中心"套壳"现象**：不少 AI 工作站/算力中心，本质是采购显卡 + 大厂 API Key，包装成"断网私有化平台"卖信息差，没有底层芯片或核心算法壁垒。在我看来就是聚合平台穿了件很牛的硬件马甲。

还有一个现场观察：会场主力是三四十岁的从业者，年轻面孔不多。行业刚起步、人才还没大规模涌入的时候，本来就是机会窗口——我是这么理解的。

## 四、我把"壁垒"划掉了

论坛说"壁垒"，展台看"壁垒"，笔记里这个词出现了一整天。晚上复盘，我把它划掉了。

我的推理链：

1. **"壁垒低"是个错觉**。行业现状确实是产品同质化、没有谁建成极强的护城河——但这不等于"壁垒低"，而是**极早期还没有人建成壁垒**。两者天差地别：前者是红海信号，后者是蓝海信号。机会很多、很大。
2. **政府下场是必然的**。Token 与电力强相关，电力与政府强相关——所以已经有地方招商局亲自下场建数据工厂给机器人公司供数据。这解释了为什么"数据/算力"会成为基础设施级别的生意。
3. **真正的护城河是"交付"而非"造楼"**。造楼（算力中心、大平台）已经被大厂和国资占位，但"在真实场景里把闭环交付跑通"这件事，谁都还没做好。谁能稳定交付，谁就有壁垒——**稳定交付本身就是壁垒**。

这三条都指向同一个结论：行业处于极早期，不应被神话焦虑，也不应贬低自身积累。

## 五、Token 经济与我手里的 VLA 闭环

论坛上反复出现一个词："真实场景闭环交付"。这句话我从早听到晚，越听越耳熟——因为它就是我每天在做的事：

- 台上的产业隐喻：算力 → Token → 按结果计费 → 交付
- 我手里的工作流：采数据 → 训练 → 推理 → 部署回真机

同一条链，两个尺度。懂一层，另一层就通了。

这也给了我一次外部验证：我手里的 VLA 训练全链路 + 真机数据经验，正是"交付能力"的一部分。行业没有壁垒 ≠ 人人能交付——展台上那么多"卖爆米花"的机械臂就是证据。我的生态位不差。

## 六、我自己的路：FDE 与复合型

参会给我的路径启发，写下来备忘：

- **阶段性方向：FDE（前沿部署工程师）**。论坛里润建股份明确把 FDE 模式当作 AI 竞争的下一阶段。纯算法研究我卷不过科班博士，但"懂算法 + 懂硬件 + 懂真实场景"的复合型路线更适合我——交付闭环恰好是我的日常。
- **终极目标：创始人**。不依赖套壳，靠懂底层算法、懂硬件、懂真实场景，创造不可替代的价值。这个目标没有变。
- **进行时声明**：以上是我当前阶段的认知，随着积累一定会被推翻修正。这篇笔记会持续迭代。
