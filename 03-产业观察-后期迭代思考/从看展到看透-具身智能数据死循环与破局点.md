# 从"看展"到"看透"：我把具身智能的"数据死循环"画了出来

**副标题：AGIC/GERX 大会认知复盘——为什么大模型已经起飞，机器人还在原地转圈**

## 一、第二天：从逛展改成听会

第一天逛展，我把"壁垒"这个词从笔记里划掉了（见[《逛了一天机器人展，我把"壁垒"这个词从笔记里划掉了》](展会观察笔记-逛了一天我把壁垒划掉了.md)）——展台上大多数东西没有太高的壁垒，有的只是"看起来像壁垒"。

第二天下午，同一场 AGIC/GERX 的论坛上，六位嘉宾的发言正好回答了我划掉那个词之后冒出来的问题：**既然没有高壁垒，那行业真正的瓶颈在哪？**

| 嘉宾/机构 | 核心观点 | 我的理解 |
|---|---|---|
| 王江平（工信部原副部长） | 必须通过高水平仿真获取高质量工程数据，才能从数字世界迁移到真实物理世界干活 | 官方口径也把"数据"当成核心瓶颈 |
| 王郸维院士 | 展台机器人只是"干净"场景的表演——"演示鲁棒性"；一到高温、浓烟、弱光就失效，必须融合毫米波等多模态才能做到"工业级鲁棒性" | 演示与工业之间隔着一整条传感器冗余的鸿沟 |

六条拼在一起，行业的画像就出来了：**极早期、缺数据、演示强、工业弱、头部开始抢交付。**

## 二、全场最值得记的一个词：鲁棒性

王郸维院士的一句话让我停下来记笔记："展台上的机器人，只是在干净场景下的表演。"

他给鲁棒性分了两层：

- **演示鲁棒性**：在固定、可控、干净的环境里稳定运行。展厅光照恒定、室温 25 度、地面平整、没有遮挡——机器人在这种环境下倒咖啡、抓爆米花十拿九稳，说明的是"算法链路能跑通"。
- **工业级鲁棒性**：在高温、浓烟、弱光、粉尘、振动、电磁干扰叠加的复合工况下仍然可靠。这时候单一传感器最先崩：双目视觉在反光、逆光、远距离下直接失效，所以必须上毫米波等多模态融合，靠传感器冗余把可靠性堆上去。

汽车行业有一对现成的概念，跟这个一模一样：**台架试验 vs 三高试验**。

发动机在台架上标定通过，不等于能上路——量产前必须拉去跑高温、高寒、高原（三高）和长里程耐久。展台上的机器人，就是台架阶段的产物；工业级鲁棒性，才是"三高标定"。

我在实习里其实已经亲手摸过这条鸿沟：机械臂的编码器在实验室里读数稳定，一上真机工况就开始漂移打滑，查了很久最后定位到硬件级问题。那一次经历，本质上就是"演示鲁棒性"和"工业级鲁棒性"之间差距的一次现场教学：**从演示到工业，中间隔着的是工程化，不是算法。**

## 三、大模型起飞，为什么具身智能还在原地

会上我一直在想这个问题，散会后想通了：

大模型的数据，是互联网过去二十年的"存货"——文字、代码、图片、视频，海量现成，直接喂。具身智能的数据，互联网上一个字节都没有，因为**真机实操数据必须从零开始采**。即使有厂商下场采数，数据量也不及大模型的万分之一。

换个汽车人的说法：大模型是"开卷考"，教材库已经堆了二十年；具身智能是"闭卷实操考"，教材得自己一本一本去写，写完一本还只考那一台机器。

## 四、数据不是 Token：一条数据换不来第二台机器人

更进一步，具身数据还有个比"少"更致命的问题：**不通用**。

Token 是通用的——不管什么手机、什么 API ID，Token 就是 Token，换个调用方照样计价。但具身数据针对性极强：它是在特定机器人的协议和 URDF 文件上采出来的，在宇树机器人上采的数据，智元机器人直接没法用。

这就像发动机标定：一套 ECU 的 MAP 图是给这一台发动机标定的，换个排量、换个进气设计，旧 MAP 图基本作废。具身数据比 MAP 图还苛刻——它连"同型号"都要求，换品牌就是废数据。

这就是"数据"和"Token"的本质差异：**Token 是货币，数据是专用零件。** 货币能流通，零件只能配套。

## 五、如果数据是瓶颈，数据工厂是不是门好生意

顺着这个逻辑，我算了算数据工厂这笔账。

现在市面上的数据工厂，本质是"代采"：采购特定厂商（比如智元）的真机，雇人遥操采数据，再把数据回笼给那家厂商。问题就出在"回笼"上——数据绑定单一品牌，只能卖给一家，无法形成规模化；一家客户的订单，摊不平真机采购和运营成本。成本极高，效率极低。

我的设想是反过来：做**低成本、标准化、跨品牌的数据工厂**——统一数据格式、统一采集规范，让一条数据能同时服务上百家机器人企业，从头部到初创都能用。客户群体大，才能赚大钱。

当然，跨品牌标准化意味着要啃下各家协议、构型、传感器布局的差异，这正是最难的部分。以上只是个人学习推演，不构成任何创业建议。

## 六、不做电池，做那个"把电池装好"的人

集成方案是另一个我在现场观察到的机会。

市面上绝大多数机器人集成方案还是实验品级别：电池不耐用，动几下就没电；返修率偏高。纯做电池，门槛极高，新能源巨头下场就能碾压，没法入局——这就像现在进场做电芯去跟巨头拼，没有意义。

但"高品质的集成方案"不一样：把电池、结构、散热、可靠性、软件调度这些工程痛点一个个解决掉，把实验品做成能交付的产品——这是主机厂的逻辑，不是零部件厂的逻辑。**做不了电芯，可以做那个把电芯装进整车、并让它跑十万公里不趴窝的人。**

## 七、死循环与两条破局路

把前面的观察串起来，这个行业目前的状态是一个死循环：

```
缺数据
  ↓
八成的订单流向科研和数据采集
  ↓
机器人停在科研和表演阶段
  ↓
产生不了真实工业订单
  ↓
拿不到真实环境的数据
  ↓
更缺数据（回到起点）
```

破局的关键，不在于再去卷大模型参数——参数战属于上一个战场。真正卡脖子的两条路：

1. **打破物理数据壁垒**：做出跨品牌标准化的数据生产能力，让一条数据服务一百家机器人企业；
2. **解决真实工况的系统级交付**：把鲁棒性（多模态融合）和能耗问题做成可交付的工程能力，而不只是实验室指标。

从"看展"到"看透"，从宏观政策到微观算账，这一天的收获是把行业的第一性原理拆到了底：**具身智能缺的不是算法，是能流通的数据和能交付的工程。**
